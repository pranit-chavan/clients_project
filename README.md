# Bhagwati Egg'swala

A static multi-page website for Bhagwati Egg'swala, a family egg supplier in Nashik.

## Pages

- `index.html` — home, story, product range, reviews, and ordering links
- `products.html` — pack catalog with search, audience filters, and pack-size sorting
- `faq.html` — frequently asked questions
- `contact.html` — contact details and WhatsApp order form

## Run locally

Requires Node.js. From the project folder, run:

```powershell
node server.js
```

Then open [http://localhost:8090](http://localhost:8090).

## Deploy

This is a static website and can be deployed directly from the repository on Vercel. No build command or output directory is required.
